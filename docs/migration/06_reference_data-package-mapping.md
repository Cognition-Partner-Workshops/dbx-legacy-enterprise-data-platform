# 06_reference_data (WWI_ReferenceData) -> Databricks package mapping

Legacy project: `ssis/06_reference_data/` (14 `REF_Load_*.dtsx`, generated by `build_reference_packages.py`).
Bundle: `databricks/06_reference_data/` (`wwi_06_reference_data`), one job `wwi_06_reference_data` with 14 notebook tasks,
task keys = legacy package names. Shared control framework: `dbx_etl_common` (session 00) - consumed, not copied.

## 3. SSIS component -> Spark construct

| SSIS construct (per `build_reference_packages.py`) | Databricks |
|---|---|
| `CTL Log Package Start` / `Success` / `Failure` (Execute SQL -> `etl.usp_LogPackageStart/End`) | `wwi_ref.runtime.packageRun(spark, p, PACKAGE_NAME)` context manager -> `control.logPackageStart`, `control.logPackageEnd(Succeeded / Failed + rowsRead/Inserted/Updated/Deleted/Rejected)`, `control.logError` on exception (re-raised) |
| `CTL Ensure Batch` (`BatchId = 0` -> open a batch) | `runtime.resolveBatchId` -> `control.startBatch(spark, catalog, "WWI_ReferenceData", batchType="Weekly", businessDate, environmentCode, allowAdoptRunning=True)` |
| `REF Load ...` Execute SQL Tasks calling `ref.usp_Load*` | `wwi_ref.ref_loads.load*(ctx)` - the stored procedure logic (steward grid vs. source rows, steward-maintained rows preserved, effective dating, lookups) as DataFrame ops + Delta `MERGE` (`delta_io.mergeReference`) |
| `REF Report Unmapped Codes` (`ref.usp_ReportUnmappedCodes`) | `ref_loads.reportUnmappedCodes(ctx, domain)` -> `silver.err_rejected_lookup_failure` + `control.logRejectedRecordSet` + `control.logRowCount` |
| Data Flow OLE DB Source (`conformed_code_query` SQL over `ref.CodeCrosswalk`) | `transforms.conformedCodeQuery` (`where EffectiveToDate is null`, `groupBy(ConformedCodeValue, coalesce(RegionCode,'ALL'))`, `max(when(IsDefaultForConformed, desc))`) |
| Derived Column (`Shape ... Dimension`, expressions, `ChangeHash`) | `withColumn` chains in `transforms.*Dimension`; `ChangeHash` = `sha2(concat_ws('|', ...), 256)` (`delta_io.changeHash`) |
| Lookup (full cache, `ref.Region` / `ref.Country` / `ref.Currency` / `ref.PostalFormatRule`), no-match output -> `err.RejectedLookupFailure` | `left` join + `where(lookupCol.isNull())` -> `ctx.rejectLookupFailures(...)` (writes `silver.err_rejected_lookup_failure` **and** `control.logRejectedRecordSet`) |
| Conditional Split (`Screen ...`, OK / Reject outputs) | `transforms.screen*` returning `(ok, rejected)`; rejected -> `ctx.rejectConstraintViolations(...)` -> `silver.err_rejected_constraint_violation` + `control.logRejectedRecordSet` |
| Aggregate (Warehouse Site movement counts), Sort | `groupBy().agg()`, `orderBy` (Delta MERGE is set based, sorts only where key assignment needs determinism) |
| Row Count transforms -> `User::RowsRead/RowsInserted/RowsRejected` -> `etl.usp_LogRowCount` | `ctx.addCounts(objectName, sourceRowCount, targetRowCount, insertRowCount, updateRowCount, deleteRowCount, rejectRowCount)` -> `control.logRowCount` per object; package totals on `logPackageEnd` |
| OLE DB Destination `Dimension.X` after `TRUNCATE` (SCD1 full refresh) | `runtime.publishScd1` -> `delta_io.publishScd1`: MERGE on business key, update when `ChangeHash` differs, insert new, `WHEN NOT MATCHED BY SOURCE ... DELETE` for rows owned by the package lineage (reserved members kept) |
| Cost Center SCD2 (`Dimension.Cost Center` `EffectiveFrom/To`, `IsCurrentRow`, `VersionNumber`, `RowHashType2`) | `delta_io.publishScd2`: full outer join on business key, new version when `RowHashType2` changes, close previous version at `EffectiveFrom - 1 second`, vanished keys closed |
| Date dimension `Derive Fiscal Calendars` / `Dimension.Date.sql` | `datecalendar.buildDateDimension`: `explode(sequence(start, end, interval 1 day))`, NA/EU/APAC fiscal columns from `silver.ref_region.FiscalYearStartMonth`, sentinel rows `-1 -> 1900-01-01`, `-2 -> 1900-01-02` |
| Unknown members (`90_unknown_members.sql`) | `reserved.seedAllReservedMembers`: `-1 Unknown`, `-2 Not Applicable`, `-3 Invalid`, `-9 Error` MERGE-inserted (`WHEN NOT MATCHED`) into every `gold.dim_*` present, typed defaults per column |
| Precedence constraints / `RestartFromStep` | `runtime.isSkippedByRestart(p, PACKAGE_NAME)` (`dbutils.notebook.exit` when the package precedes the restart step in `wwi_ref.PHASES`); job `depends_on` edges for cross-package order |
| Event handler `OnError` -> `etl.usp_LogError` | `packageRun.__exit__` -> `control.logError(...)`, then `logPackageEnd(status="Failed")`, exception re-raised so the task fails |
| Package parameters `BatchId`, `BusinessDate`, `ReloadFullHistory`, `EnvironmentCode`, `RestartFromStep` | `params.getJobParams(dbutils)`; `DateRangeStart` / `DateRangeEnd` (DateDimension only) via `runtime.widgetOrDefault` |

## 4. Control-framework calls

| Legacy | `dbx_etl_common` call (where) |
|---|---|
| `etl.usp_StartBatch` | `control.startBatch` (`runtime.resolveBatchId`, only when `BatchId = 0`) |
| `etl.usp_LogPackageStart` / `usp_LogPackageEnd` | `control.logPackageStart` / `control.logPackageEnd` (`runtime.packageRun`) |
| `etl.usp_LogError` | `control.logError` (`packageRun`, `ctx.logWarning` with `errorSeverity="Warning"`) |
| `etl.usp_LogRowCount` | `control.logRowCount` (`ctx.addCounts`, one row per legacy object; validation notebook: `reconcile:<object>`) |
| `etl.usp_LogRejectedRecordSet` | `control.logRejectedRecordSet` (`ctx._writeRejects`, alongside the `silver.err_*` mirror) |
| `etl.usp_GetConfiguration` | `control.getConfiguration` (`ref_loads.codeSetConfiguration`) |
| `etl.usp_EndBatch` | not called here - the batch is ended by the master job (session 00), exactly as `Master_Weekly_Reference_Load` does |

Wheel: every task runs in the serverless environment `dbx_etl_common` (`client: "3"`) whose dependency is
`../../common/dbx_etl_common/dist/*.whl` - the same relative reference the 00 master jobs use, so `python -m build --wheel` in
`databricks/common/dbx_etl_common` before `bundle deploy` is all that is needed. The bundle's own helpers (`src/wwi_ref`) are added to
`sys.path` from the bundle's workspace files path by each notebook.

## 6. Validation

`validation/REF_Reconcile_ReferenceData.py` profiles every `silver.ref_*`, `silver.err_*` and `gold.dim_*` table above (row count,
business/reserved row counts, per-`BatchId` counts, `sum(xxhash64(concat_ws('|', business columns)))`), compares with a baseline
supplied as `${catalog}.etl.reference_baseline` or the `BaselineJson` parameter, ports `02_row_count_reconciliation.sql` #1 (hop
variance per package) and `03_dimension_fact_integrity.sql` #7 (Date coverage) and checks the reserved members, then writes to
`etl.row_count_log` through `control.logRowCount`. It is not a task of the job (the job must have exactly the 14 package tasks); run it
as a one-off notebook or add it to the 00 master validation job.

## 7. Not migrated / needs decision

| Item | Status / reason |
|---|---|
| Steward grids (`ref.usp_Load*` `VALUES (...)` blocks) | Ported to `src/wwi_ref/grids.py` **from the intent in the generator and the procedures' shape**, not from a production data extract. Before go-live the grids must be reconciled against the SQL Server `ref.*` content (run the validation notebook with a baseline). Rows a steward edited in SQL Server (`MaintainedByName <> package`) have to be copied over once; the loaders will not overwrite them afterwards. |
| `etl.Configuration` writes (`RefCodeSet.*` rows from CodeTranslation) | The contract has `getConfiguration` only; rows are MERGEd directly into `etl.configuration` with the legacy column names. Decision: keep, or ask session 00 for `control.setConfiguration`. |
| `err.*` reject tables **and** `etl.rejected_record` | Both are written (legacy had only `err.*`; the contract offers `logRejectedRecordSet`). Duplicate storage is deliberate so `validation/runtime` queries over `err.*` still port; drop one if not wanted. |
| Surrogate keys | Legacy `IDENTITY`; here `max + row_number()` on the business key. Keys are stable across re-runs but differ from SQL Server values - facts must be re-keyed via business keys (07/08 already do that). |
| `Dimension.Date` range | Legacy hard-coded 2005..2035 is now `DateRangeStart/End` parameters with the same defaults. The spine is regenerated on every run and MERGEd on `DateKey` (insert missing, update changed), so widening the range is additive and re-runs are no-ops. |
| Fiscal calendar for `APAC` | `FiscalYearApac` is named by the year the fiscal year **starts** in (per the SSIS derived-column comment), `NA` by the year it ends in. Confirm with finance - this is exactly the legacy behaviour but is a common source of dispute. |
| Warehouse Site source | Legacy reads `stg.StockMovement` (owned by 04) for movement counts and infers site metadata from the movements; there is no site master. If 04 changes the staging shape, `ref_loads.warehouseSiteMovements` must follow. |
| `ReloadFullHistory` | Meaningless for steward grids and the generated calendar (always full, idempotent MERGE); accepted for contract compatibility but has no effect in this project. |
| Serverless environment | Job uses `environments` (serverless, `client: "3"`). If the workspace mandates classic clusters, replace with `job_clusters` + `libraries: - whl:`. |
| Warehouse Site postal rule join | The legacy source query joins `ref.PostalFormatRule AS p ON p.CountryCode = c.CountryCode AND p.RulePriority = 1`, but every steward row has `RulePriority` 100, 110, 200, ... - so no rule ever matches, `TruncateToLength` is NULL and `PostalCodeStandardized` is only upper-cased/stripped (US `90210-1234` -> `902101234`, never ZIP5). Ported **as is** (`transforms.warehouseSiteDimension` filters `RulePriority == 1`). Decision: keep the legacy output, or change the filter to the lowest priority per country so the `ZIP5 only` rule note becomes true (one-line change, changes `PostalCodeStandardized` for every US/CA site). |
| Unmapped-code report (`DFT Scan For Unmapped Codes`) | Ported 1:1 as a rolling view over `silver.err_rejected_lookup_failure` (payload `{"DOMAIN","CODE"}` rows only, like `ref.vw_UnmappedSourceCode`). As in the legacy, the scan runs **before** the package's own all-domain sweep (`Report Unmapped Codes - All Domains`), so a first run reports only codes swept by earlier packages and a re-run reports the full set; rows of the same BatchId are replaced, not duplicated. |
| `databricks bundle validate -t dev` / `-t prod` | Both `Validation OK!` with the `DATABRICKS_DEMO_*` credentials (no deploy, nothing run in the workspace). |
