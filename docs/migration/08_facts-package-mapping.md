# 08_facts (WWI_Facts) -> Databricks package mapping

Source: `ssis/08_facts/` (24 `FACT_*.dtsx`, generated by `build_fact_packages.py`) plus the fact load / correction
procedures under `sqlserver/procedures/facts/` and the fact DDL under `sqlserver/warehouse/facts/`.
Target: bundle `databricks/08_facts/` (`bundle.name = wwi_08_facts`), one job `wwi_08_facts` with 24 tasks keyed by the
legacy package name, one Python notebook per package under `notebooks/`, shared helpers under `src/`, reconciliation under
`validation/`, pytest under `tests/`.

## 3. Dimension lookups per package (legacy Lookup semantics)

Lookup = `fact_common.lookupDimension`: SCD2 dims join on business key **and** `valid_from <= eventDate < valid_to`
(open row `valid_to = 9999-12-31 23:59:59`), type-1 dims on business key + `is_current`. Reserved keys: `-1` unknown,
`-2` not applicable (nullable optional keys such as promotion), `-3` invalid, `-4` inferred-pending, `-9` error, `0` not assigned.

| Package | Lookup (dimension : on miss) |
|---|---|
| FACT_*_Load_Sale | Customer : infer + queue; Stock Item : **hold**; Salesperson : -1; Promotion : -2 when null else -1; City (EU ship-to) : -1 |
| FACT_Load_Order | Customer : infer; Stock Item : hold (`HoldRetryLimit`); Salesperson : -1; Promotion : -1 |
| FACT_Load_Purchase | Supplier : infer; Stock Item : hold |
| FACT_Load_PurchaseReceipt | Supplier : infer; Stock Item : -1 |
| FACT_Load_Payment | Customer : hold |
| FACT_Load_SupplierPayment | Supplier : -1 |
| FACT_Load_Movement | Stock Item : infer; Warehouse Site (from / to) : -1 |
| FACT_Load_StockHolding / Daily*Snapshot | none - staging already carries surrogate keys; null -> -1 |
| FACT_Load_Transaction | Customer : -1; Supplier : -1; Transaction Type : -1 (party split by `party_business_key`) |
| FACT_Load_CustomerTransaction | Customer : infer; Transaction Type : -1 |
| FACT_Load_SupplierTransaction | Supplier : infer; Transaction Type : -1 |
| FACT_Load_Shipment | Customer : infer; Carrier : -1; Warehouse Site : -1 |
| FACT_Load_Return | Customer : infer; Stock Item : -1; Return Reason : -1 |
| FACT_Load_CreditNote | Customer : infer |
| FACT_Load_LoyaltyPoints | Customer : infer; Promotion : -1 |
| FACT_Load_WebSession | Customer : -1; Promotion : -1 |
| FACT_Load_OrderFulfilment | Customer : infer |
| FACT_Load_GLPosting | GL Account : -1 |

* **infer** = `Integration.usp_InsertInferredMember` port (`fact_common.inferMembers`): stub row with
  `inferred_member_flag = true`, `valid_from = 2013-01-01`, open `valid_to`, plus a `silver.work_late_arriving_dimension_queue`
  entry (`_queue_late_arrivers` Execute SQL Task). The fact row keys to the new stub, not to -1.
* **hold** = `Fact.[Fact Load Hold]` pen (`fact_common.holdRows` / `splitHeld` / `settleHolds`): the row is parked with
  `retry_count = 0`, `max_retry_count` = regional retry limit (NA 3, EU 7, APAC 21, default 5; `HoldRetryLimit` on Order),
  replayed every run (`LoadHeldRows = 1`), released when the dimension arrives, and loaded against `-1` with a `HOLD_EXPIRED`
  reject once `retry_count + 1 >= max_retry_count` (the row is held for exactly `max_retry_count` runs, matching the
  package parameter description "runs a line may be held before it is loaded against the unknown member").
* A held row that re-arrives from staging in the same window as its replay is coalesced (`coalesceHeldReplays`): the fresh
  payload wins, the hold is settled.

## 4. SSIS component -> Spark construct

| SSIS component (generator helper) | Spark / Delta construct |
|---|---|
| `log_package_start` / `log_package_end` Execute SQL (`etl.usp_LogPackageStart/End`) | `with control.packageRun(spark, catalog, batchId, PACKAGE_NAME, projectName="WWI_Facts", stepName=...) as run:` |
| `get_watermark` / `set_watermark` (`etl.usp_GetWatermark/SetWatermark`) | `control.getWatermark` / `control.setWatermark` (`fact_common.loadWindow`, `inWindow`) |
| OLE DB Source with `LoadedAtUtc BETWEEN ? AND ?` | `readTable(...).where(ts > wmFrom & ts <= wmTo)`; `ReloadFullHistory` -> epoch window |
| Sale `BackDatingDays` window (five days NA) | `loadDates`: `min(watermarkDate, businessDate) - backdating` from `etl.configuration` `Fact.Sale.BackDatingDays` |
| Derived Column (SSIS expressions: amounts, tax, fiscal year, hash) | `withColumn` expressions in `src/fact_rules.py` (`naturalKeyHash` = `sha2(concat_ws('|', ...), 256)`) |
| Conditional Split "Structurally valid" / error output | `fact_common.splitValid` -> valid / rejected DataFrames; rejects -> `control.logRejectedRecordSet` |
| Lookup (full cache, no-match output) on SCD2 / type-1 dims | `lookupDimension` left join with effective-date predicate + `missFlag` column |
| Lookup no-match -> "Insert Inferred Member" OLE DB Command | `inferMembers` (append to `gold.dim_*`) + `queueLateArrivers` |
| Lookup no-match -> `Fact.[Fact Load Hold]` insert | `holdRows`; "Load Held Rows" step = `readHeldRows` union + `coalesceHeldReplays` |
| Union All (fresh + held) | `DataFrame.unionByName` |
| Aggregate / Sort / Row Number | `Window.partitionBy(...).orderBy(...)` (`rankLatest`, `saleDuplicateRank`) |
| OLE DB Destination + `Integration.usp_LoadFact*` MERGE | `fact_common.mergeFact`: Delta `MERGE ... ON target.<key> = source.<key> WHEN MATCHED AND changed UPDATE WHEN NOT MATCHED INSERT` |
| `DELETE ... WHERE [Snapshot Date] = ?` + insert | `replaceDateRange` -> `df.write.option("replaceWhere", "<date_key> = ...")` |
| Row Count transforms + `etl.usp_LogRowCount` | `control.logRowCount(spark, catalog, packageExecutionId, objectName, sourceRowCount=..., insertRowCount=..., updateRowCount=..., deleteRowCount=..., rejectRowCount=...)` using Delta `operationMetrics` |
| Error output -> `etl.usp_LogRejectedRecord(Set)` | `control.logRejectedRecordSet(... rejectStage="Fact", rejectReasonCode=...)` |
| OnError event handler -> `etl.usp_LogError` | `control.packageRun` context manager (logs `Failed` + `logError`, re-raises) |
| Precedence constraints / `Master_*` order | job `depends_on` edges in `resources/wwi_08_facts.yml` |
| Package parameters (`BackDatingDays`, `HoldRetryLimit`, `DedupWindowDays`, `ReportOnly`, `ExpiryMonths*`) | `control.getConfiguration(spark, catalog, "Fact.<Object>.<Param>", environmentCode)` with the package default as fallback (`fact_common.configurationValue`) |
| EU FX lookup (`ref.CurrencyExchangeRate` effective rate) | `lookupEffectiveFxRate` (latest rate on or before invoice date; APAC `priorDayOnly` variant for the "Retry Held Lines With Prior Day Rate" step; `FX_RATE_MISSING` hold when no rate) |

### Regional sale rules preserved (`validation/runtime/04_regional_divergence.sql`)
* NA: `RegionCode = 'NA'`, 5-day backdating, draft invoices excluded, source sales tax kept as-is, fiscal year = calendar year.
* EU: effective-dated FX to reporting currency, VAT recomputed from `stg_tax_rate` by ship-to country, reverse charge
  (zero VAT, `reverse_charge_flag`) for registered intra-EU customers, ship-to city lookup.
* APAC: GST inclusive/exclusive split, GST-free items, fiscal year starting April, FX source code preserved
  (`fx_rate_source`), distributor rebate accrual into `silver.int_fact_sale_apac_rebate`.

### FACT_Apply_Corrections (`Integration.usp_ApplyFactCorrections`)
* `Fact.Sale`: insert negated `REV` row + restated `RES` row, both `corrected_sale_key = original sale_key`,
  `restatement_version + 1`.
* `Fact.Payment`: in-place update of allocated / unallocated amount, restatement version, restated datetime, batch, load datetime.
* `Fact.Order`: in-place update of quantity ordered, net order amount, reporting amount, batch, load datetime.
* Other targets: `CORR_FACT_UNSUPPORTED` reject; every request stamped `AppliedDatetime` / `AppliedBatchId`.

### FACT_Dedup_Sale (`Integration.DeduplicateFactSale`)
`ROW_NUMBER() OVER (PARTITION BY natural_key_hash ORDER BY COALESCE(source_row_version,0) DESC, sale_key DESC)` over `ORIG`
rows inside `[BusinessDate - DedupWindowDays, BusinessDate]`; losers archived to `gold.fact_sale_duplicate_archive` then
deleted; `ReportOnly` skips the delete.

## 5. Control framework usage

Every notebook: `# Databricks notebook source` header, `p = params.getJobParams(dbutils)`, `catalog = p["catalog"]`,
`batchId = fact_common.resolveBatchId(spark, catalog, p)` (adopts the running batch when `BatchId = 0`, mirroring
`usp_StartBatch(@AllowAdoptRunning = 1)` in the master packages), then `control.packageRun(...)` wrapping the load.
Inside the run: `control.getWatermark` / `setWatermark`, `control.getConfiguration`, `control.logRowCount`,
`control.logRejectedRecordSet` / `logRejectedRecord`, `control.logError` (through `packageRun`). The reconciliation notebook
additionally calls `control.assertRowCountReconciliation(spark, catalog, batchId, raiseOnFailure=False)`.
`dbx_etl_common` is consumed as the wheel `../common/dbx_etl_common/dist/dbx_etl_common-*.whl` (bundle variable `common_wheel`,
installed as a task library on every task); nothing from `databricks/common/` is copied. `tests/fakes/dbx_etl_common/`
is a test-only stand-in for local pytest.

## 6. Parameters

Job parameters (all strings, from `databricks.yml` variables): `BatchId` (`"0"`), `BusinessDate` (`yyyy-MM-dd`, empty =
today), `ReloadFullHistory` (`"False"`), `EnvironmentCode` (`DEV`/`PROD`), `RestartFromStep` (`""`, forwarded for parity),
`catalog` (`wwi_${bundle.target}`). Package-level SSIS parameters are read from `etl.configuration` with the generator
default as fallback: `Fact.Sale.BackDatingDays` (5), `Fact.Sale.DedupWindowDays` (90), `Fact.Sale.DedupReportOnly`,
`Fact.Order.HoldRetryLimit` (3), `Fact.LoyaltyPoints.ExpiryMonthsNa/Eu`, regional hold retry limits.
Reconciliation notebook widgets: `BaselineTable` (Delta table of SQL Server figures), `BaselineJson`, `LookbackMonths`.

## 7. Partitioning / clustering decisions

* Transactional facts (`fact_sale`, `fact_order`, ... 17 tables): **liquid clustering** `CLUSTER BY (<date_key>, region_code)`
  (`fact_common.ensureTable(clusterCols=...)`). Daily partitions would be far too small for the WWI volumes and would
  fragment the MERGE; the date key still gives file skipping for `BusinessDate` windows and the regional divergence checks.
* Periodic snapshots (`fact_daily_inventory_snapshot`, `fact_daily_sales_snapshot`) and the as-at position
  `fact_stock_holding`: **partitioned** by `snapshot_date_key` / `as_at_date_key` so the nightly `replaceWhere` swaps exactly
  one partition, matching the legacy `DELETE WHERE Date = ?` + insert.
* `gold.fact_fact_load_hold`, `gold.fact_sale_duplicate_archive`, `silver.work_late_arriving_dimension_queue`: unclustered
  small tables.

cd tests && DELTA_JARS=<delta-spark jar>,<delta-storage jar> python -m pytest -q      # local PySpark 3.5 + Delta 3.2

hashes to `etl.row_count_log`, and compares them with the SQL Server baseline supplied as a Delta table or JSON.

## 9. Not migrated / needs decision

| Item | Status / why |
|---|---|
| `FACT_Rekey_LateArrivingDimensions` (consumer of `work.LateArrivingDimensionQueue`) | Not part of `ssis/08_facts`; the queue is written here, the rekey sweep belongs to the dimension project. |
| SSIS `ExtractAttempt` retry loop / `RestartFromStep` | Handled by the master orchestration (session 00); the fact job forwards `RestartFromStep` but has a single step group. |
| `HoldRetryLimit` boundary | Implemented as "held for exactly N runs, loaded against -1 on run N+1" per the package parameter text; `Fact.[Fact Load Hold]` DDL says "until Retry Count reaches Max Retry Count". Confirm N vs N-1 if the legacy sweep is observed to release one run earlier. |
| Snapshot `replaceWhere` key | `FACT_Load_DailySalesSnapshot` legacy deletes by `Invoice Date Key = snapshot date`; the port replaces by `snapshot_date_key`, identical only while the staging feed is same-day (it is today). |
| `Fact.Sale.BackDatingDays` on first load | With no watermark the legacy `usp_GetWatermark` returns the epoch and the sale load takes full history; kept as-is (no backdating cut on first run). |
| Delta `operationMetrics` for row counts | Insert/update/delete counts come from the Delta commit metrics rather than SSIS Row Count transforms; a MERGE that changes nothing produces no commit and is logged as 0. |
| Physical fact DDL (`sqlserver/warehouse/facts/*.sql` constraints, `Lineage Key` FK, filtered indexes) | Tables are created on first write from the DataFrame schema with `CLUSTER BY`; FKs/indexes have no Delta equivalent. Unity Catalog informational FKs can be added later if wanted. |
| `dbx_etl_common` interface | Aligned with session 00's PR #38 (`dbx_etl_common` 0.1.0): `getWatermark`/`setWatermark` exchange ISO strings (`yyyy-MM-ddTHH:mm:ss.fff`), parsed/formatted in `fact_common.parseWatermark` / `watermarkValue`; the wheel is `databricks/common/dbx_etl_common/dist/dbx_etl_common-0.1.0-py3-none-any.whl` (build with `python -m build --wheel` before `bundle deploy`, or add the same `artifacts:` block). |
| `validation/static/run_all_checks.py` forbidden-content rule | Fires on every Databricks artifact (`# Databricks notebook source`, `dbutils`); PR #38 carves out `databricks/` and `docs/migration/` in that one check. This PR does not touch `validation/`; it is clean with #38's checker. |
